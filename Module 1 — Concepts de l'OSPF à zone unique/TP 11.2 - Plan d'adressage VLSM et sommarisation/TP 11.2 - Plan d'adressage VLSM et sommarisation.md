## R-RENENS : 

```
en
conf t
hostname R-RENENS

interface fa0/0
ip add 10.10.0.177 255.255.255.252
no shutdown
exit

interface fa1/0
ip add 10.10.0.161 255.255.255.240
no shutdown
exit

interface fa2/0
ip add 10.10.0.129 255.255.255.224
no shutdown
exit

interface fa3/0
ip add 10.10.0.1 255.255.255.128
no shutdown
exit

router ospf 1
router-id 1.1.1.1
network 10.10.0.177 0.0.0.0 area 0
network 10.10.0.0 0.0.3.255 area 1
area 1 range 10.10.0.0 255.255.252.0
exit

do wr
```

## Liaisons P2P : 

```
en
conf t
hostname Liaisons-P2P

interface fa0/0
ip add 10.10.0.178 255.255.255.252
no shutdown
exit

router ospf 1
router-id 2.2.2.2
network 10.10.0.176 0.0.0.3 area 0
exit

do wr
```
