# TP 14.1 - Découverte des API REST et du format JSON

## Exercice pratique

#### Analyser cette réponse JSON et en extraire à la main les informations demandées :

```
{
  "interfaces": [
    {"name": "Gi0/0", "status": "up", "ip": "10.0.0.1"},
    {"name": "Gi0/1", "status": "down", "ip": null}
  ]
}
```

Dans cette réponse JSON, nous avons le nom de chaque interface présente (Gi0/0 et Gi0/1), avec leur statut (UP pour Gi0/0 et DOWN pour Gi0/1) ainsi que l'adresse IP attribué à cette interface (10.0.0.1 pour Gi0/0 et aucune adresse IP pour Gi0/1).

### Combien d'interfaces sont "up" ?

Il y a une interface sur deux qui est UP, c'est Gi0/0.

### Quelle est la syntaxe pour accéder à l'IP de la première interface en Python ?

data["interfaces"][0]["ip"]
