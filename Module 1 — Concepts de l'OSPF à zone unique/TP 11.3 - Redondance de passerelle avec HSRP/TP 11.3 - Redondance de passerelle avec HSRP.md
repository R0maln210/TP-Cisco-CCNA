## R1-ACTIF : 

```
en
conf t
hostname R1-ACTIF

interface fa0/0
ip add 10.0.5.2 255.255.255.0
standby 5 ip 10.0.5.1
standby 5 priority 110
standby 5 preempt
no shutdown
exit

do wr
```

## R2-SECOURS : 

```
en
conf t
hostname R2-SECOURS

interface fa0/0
ip add 10.0.5.3 255.255.255.0
standby 5 ip 10.0.5.1
standby 5 priority 100
no shutdown
exit


do wr
```
