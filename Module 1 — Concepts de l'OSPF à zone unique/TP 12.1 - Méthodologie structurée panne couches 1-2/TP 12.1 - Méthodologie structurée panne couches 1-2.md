# TP 12.1 - Méthodologie structurée : panne couches 1-2

## Commandes à documenter : 

### On part de la couche la plus basse pour monter progressivement jusqu'à la couche la plus haute

```
1. Couche 1 — Physique
PC1> ipconfig /all
SW1# show interfaces status
SW1# show interfaces fa0/1

2. Couche 2 — Liaison de données
SW1# show vlan brief
SW1# show interfaces fa0/1 switchport

3. Couche 3 — Réseau
PC1> ping 192.168.20.1
R2# show ip interface brief
```

## 1. Couche 1 - Physique

```
# On regarde l'adresse IP du VPC pour voir si son adresse et bonne et si il est dans le bon sous réseau
PC1> ipconfig /all

# On regarde si les interfaces sont bien UP pour pouvoir transmettre des données
SW1# show interfaces status

# On regarde spécifiquement l'interface fa0/1 pour voir son adresse IP et si elle est UP ou DOWN
SW1# show interfaces fa0/1
```

## 2. Couche 2 - Liaison de données

```
# On regarde la configuration du ou des VLAN
SW1# show vlan brief

# On regarde le switchport de l'interface fa0/1
SW1# show interfaces fa0/1 switchport
```

## 3. Couche 3 - Réseau

```
# On regarde si le PC1 arrive à communiquer avec le routeur R2
PC1> ping 192.168.20.1

# On regarde si les interfaces de R2 sont UP ou DOWN
R2# show ip interface brief
```
