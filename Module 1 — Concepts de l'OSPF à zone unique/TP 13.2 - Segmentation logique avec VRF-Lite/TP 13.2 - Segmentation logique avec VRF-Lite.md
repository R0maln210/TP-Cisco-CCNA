# TP 13.2 - Segmentation logique avec VRF-Lite

## Lab complet : 

![01 - lab complet](https://hackmd.io/_uploads/ryk1UKfqfe.png)

## R1 : 

```
en
conf t
hostname R1

ip vrf CLIENT-A
rd 65001:1
exit

ip vrf CLIENT-B
rd 65001:2
exit

interface fa1/0
ip vrf forwarding CLIENT-A
ip add 192.168.1.1 255.255.255.0
no shutdown
exit

interface fa2/0
ip vrf forwarding CLIENT-B
ip add 192.168.1.1 255.255.255.0
no shutdown
exit

interface Loopback 0 
ip add 8.8.8.8 255.255.255.255
no shutdown
exit

do wr
```

## PC-CLIENT-A : 

```
set pcname PC-A
ip 192.168.1.10 255.255.255.0 192.168.1.1
save
```

## PC-CLIENT-B : 

```
set pcname PC-B
ip 192.168.1.10 255.255.255.0 192.168.1.1
save
```
