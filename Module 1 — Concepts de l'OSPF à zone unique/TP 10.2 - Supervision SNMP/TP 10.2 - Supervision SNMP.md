## R1 : 

```
en
conf t
hostname R1

interface fa0/0
ip add 10.0.0.254 255.255.255.0
no shutdown
exit

snmp-server community S@tomRO2026 RO
snmp-server trap-source fa0/0

snmp-server location "Salle serveur - Campus Genève"
snmp-server contact "IT Satom - it@satom.ch"

snmp-server host 10.0.0.200 version 2c S@tomRO2026
snmp-server enable traps

do wr
```

## Serveur de supervision : 

```
en
conf t
hostname SRV-SUPERVISION

interface fa0/0
ip add 10.0.0.200 255.255.255.0
no shutdown
exit

ip route 0.0.0.0 0.0.0.0 10.0.0.254

no ip routing
ip default-gateway

exit
wr
```
